# ChatGPT

ChatGPT reaches Exact Online AI Connect through **Developer Mode**, currently in beta. It requires a **paid** plan (Plus, Pro, Business, Enterprise, or Edu), not the Free plan. On Business and Enterprise, an admin must enable Developer Mode for the workspace before you can add a connector.

## Steps

1. Go to **Settings → Connectors → Advanced → Developer mode** and enable it.
2. Add the MCP URL: `https://mcp-exactonline.iwebdevelopment.com`
3. Authorize with your Exact Online account when prompted.

See the [compatibility matrix](https://github.com/iwebdevnl/exact-online-ai-connect#client-compatibility) (last verified 2026-07).
