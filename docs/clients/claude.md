# Claude (web + Desktop)

Claude connects to Exact Online AI Connect as a custom connector. Works on all Claude plans, including the free plan (free allows one custom connector); on Team and Enterprise, an owner can add it org-wide so the whole team gets it automatically.

Use the custom-connector UI described below, not the local desktop config file.

## Steps

1. Go to **Settings → Connectors → Add custom connector**.
2. Paste the base URL: `https://mcp-exactonline.iwebdevelopment.com`
3. Authorize with your Exact Online account (OAuth, opens in your browser).

That is it, no tokens, no manual JSON.

See the [compatibility matrix](https://github.com/iwebdevnl/exact-online-ai-connect#client-compatibility) (last verified 2026-07).
