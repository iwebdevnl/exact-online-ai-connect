# Security Policy

## Reporting a vulnerability

Email **support@iwebdevelopment.com**. Do **not** open a public GitHub issue for
security reports.

Please include steps to reproduce and any relevant logs. We aim to acknowledge
within a few business days and will keep you updated on remediation.

## Supported version

Exact Online AI Connect is a hosted service; the supported version is always the live
deployment at https://mcp-exactonline.iwebdevelopment.com. There are no older
versions to patch.

## security.txt

The source of our `security.txt` lives in this repository under `.well-known/`,
but the authoritative file is served by the host at
https://mcp-exactonline.iwebdevelopment.com/.well-known/security.txt. Its
`Expires` date must be renewed before it lapses.

## Scope

This repository contains configuration and documentation only. The service and
its data processing are governed by iWebDevelopment's Algemene Voorwaarden (AV).
