# Contributing

Thanks for your interest. This repository holds the connection and plugin files
for the hosted Exact Online AI Connect MCP server. The server itself is proprietary and
hosted by iWebDevelopment.

## Reporting issues

- Bugs and connection help: open an issue using the templates.
- Security vulnerabilities: do not open an issue. See `SECURITY.md` and email
  support@iwebdevelopment.com.
